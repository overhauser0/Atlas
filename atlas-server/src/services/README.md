# Service conventions

Service は業務ルール、入力の検証、複数 repository の調整、外部クライアントへの通知を担当する。

## File structure

1. パンくずコメント
2. import
3. 型定義・非公開ヘルパー
4. 読み取り処理
5. 作成・Upsert処理
6. 更新処理
7. 削除処理
8. 同期・一括処理などの補助処理

## Comments

- 各ファイルの先頭に `// atlas-server/src/services/<filename>` を置く。
- 公開関数の説明には、簡潔な日本語の JSDoc を付ける。
- 実装から明らかな処理にはコメントを付けない。
- 複数の repository や外部APIを調整する処理では、判断理由が分かるコメントだけを残す。
- 番号付きの飾り見出しや絵文字付きの作業メモは追加しない。
- ドメインが切り替わる大きなまとまりには、必要に応じて英語の短いセクションコメントを付ける。

## Logging and errors

- 通常の進捗確認を目的とした `console.log` は使わない。
- 予期しないエラーを記録する `console.error` は、serviceで処理を継続または再送出する場合に限り使用する。
- エラーを握りつぶさず、controller層でHTTPレスポンスへ変換できるよう再送出する。
- 外部APIや同期処理のログには、対象を特定できる最小限の文脈を含める。
